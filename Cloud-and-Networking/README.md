Project 1: Cloud and Networking Concepts
Overview

This project examined real-world cloud computing scenarios and networking concepts through two case studies. The focus was on cloud scalability, infrastructure management, cloud service models, and the shared responsibility model.

Case Study 1: CrossCountry UK Train Service
Business Problem

The CrossCountry train booking system experiences significant traffic spikes during peak hours. Their on-premises infrastructure struggles to scale efficiently while maintaining cost control.

Proposed Solution

Implement Infrastructure as a Service (IaaS) within a public cloud environment.
